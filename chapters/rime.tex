音位/a/存在音位变体[ɐ]、[a]、[ɑ]，其中[a]出现在韵尾/n/之前、[ɑ]出现在韵尾/ŋ/之前，其他情况下均为[ɐ]。例如[sman]“药”、[mɑŋmə̂]“军队”、[tə-smɐ̂t]“下半身”。

音位/ə/存在音位变体[ə]、[ɤ]、[ɿ]。出现在软腭音的开音节词尾时为[ɤ]，例如[skɤ̂]“佛”、[tekʰɤ̂]“一万”、[tɑ-ŋɡɤ̂]“背部”、[kɐ-rŋɤ̂]“蹲”。出现在齿龈、龈后的擦音、塞擦音（即/s, z, ʃ, ʒ, ts, tsʰ, dz, tʃ, tʃʰ, dʒ/）后的开音节词尾时为[ɿ]，例如[tə-tʃɿ]“水”、[kə-tsɿ]“猴子”、[tsʰɿ]“野葱”、[tɐ-ʃɿ]“血”、[kɐ-ʒɿ]“告状”、[tə-dʒɿ̂]“皮肤”、[kɐ-zɿ]“管教”、[kɐ-sɿ]“倚靠”等。

对于以/j/、/w/为韵尾的韵母，不将韵母视为双元音，而视为韵核加上辅音韵尾的理由是其在音系过程中展现出与其它辅音韵尾一致的行为。正如在\ref{reduplication}节看到的，部分重叠过程中滋生音节会删除原音节的韵尾部分，而/j/、/w/同样会被删除。例如：

     $\sigma_{1}$ $\sigma_{2}'$ $\sigma_{2}$ \\
\end{exe}

\begin{exe}

\subsection{形态过程中的韵尾复辅音}\label{codacom}

同时，米亚罗话的形态过程也会产生其他复辅音韵尾。目前观察到，米亚罗话形态过程能够生成的复辅音韵尾有/nɲ/、/mɲ/、/ŋɲ/、/nʃ/、/mʃ/、/ŋʃ/、/kʃ/、/pʃ/、/wj/、/kj/、/js/、/mjs/、/pjs/。和白湾话观察到的现象类似，这些复辅音韵尾都是在人称索引的形态过程中生成的\cite[68-69]{zhang2016phonologie}。

人称索引是一种动词形态句法系统，通过在动词上附着人称形式标记小句的核心论元\cite{Haspelmath2013-mu}。四土嘉绒语的动词形态存在人称索引的现象，现有研究已经描写了卓克基话\cite{Lin-2016-dr}、白湾话\cite{Zhang2018-qm,Zhang2020-ya}、脚木足话\cite{prins2011web}、沙石多话\cite{Sun2015-ss}。米亚罗话同样也存在一套完整的人称索引系统。

当动词可以携带多个论元时，米亚罗话采用正向—反向系统，通过共情层级来决定动词携带哪个论元的标记\cite{DeLancey1981-pq,Zuniga2002-yv,Jacques2014-pu}。但无论是及物动词或不及物动词，所使用的人称索引后缀均只有表\ref{perindex}中的那些，因此本文在此不赘述米亚罗话多论元情况下的人称索引系统。

当动词是闭音节时添加人称索引后缀/ŋ, n, ɲ, j, ʃ, nʃ/，其韵尾会产生一系列音系过程，最终产出新的韵尾。本文以/ka-pʰâk/“砍”、/ka-lât/“写”、/ka-tup/“打”、/ka-ndûn/“读”、/ka-rwâs/“起床”、/ka-wzaps/“注意”、/ka-nəpjâms/“烤火”七个动词为例，描写在/-k, -t, -p, -n, -s, -ps, -ms/韵尾的动词后添加人称索引后缀时，新的韵尾的生成过程。

\subsection{形态—音系过程的形式分析}

对于上文涉及的诸多形态—音系过程，本节将其纳入生成音系学的有序规则推导框架\parencite{Chomsky1968-sp,hayes2011introductory}加以统一刻画。本文假定：每一屈折形式都对应一个由词干韵尾与人称索引后缀线性拼接而成的底层形式，底层形式经一组带有外在排序的改写规则逐条施用，最终导出表层形式。每条规则写作 $A\rightarrow B\;/\;C\,\rule[2pt]{1em}{0.4pt}\,D$，意为成分 $A$ 在环境 $C\,\rule[2pt]{1em}{0.4pt}\,D$ 中实现为 $B$，且规则对整条线性表达同时施用\parencite{Chomsky1968-sp}。本文为米亚罗话复辅音韵尾的派生构造了如下八条规则：

\begin{enumerate}
    \item[P1] \textbf{2\textsc{sg}后缀删除}：2\textsc{sg}后缀/n/在任何辅音韵尾之后删除。该规则只作用于2\textsc{sg}这一特定词缀：
    \[ \text{n}_{2\textsc{sg}}\rightarrow\emptyset\ \;/\;\ \text{C}\,\rule[2pt]{1em}{0.4pt}\,]_{\sigma} \]
    \item[P2] \textbf{/j/前韵尾调整}：在1\textsc{pl}后缀/j/前，齿龈非延续音/t, n/删除、双唇爆发音/p/弱化为滑音/w/、软腭爆发音/k/不变。三种结果共享同一环境：
    \[ \{\,\text{t, n}\rightarrow\emptyset,\ \ \text{p}\rightarrow\text{w},\ \ \text{k}\rightarrow\text{k}\,\}\ \;/\;\ \rule[2pt]{1em}{0.4pt}\,\text{j} \]
    \item[P3] \textbf{咝音换位}：词干韵尾咝音/s/与紧邻其后的响音$\mathrm{X}_{[+\text{son}]}$互换线性次序\footnote{换位是一类有标记的线性重组操作，在类型学上多见于咝音与响音相邻的语境\parencite{blevins2004evolution,hume2004indeterminacy}。}：
    \[ \text{s}\ \mathrm{X}_{[+\text{son}]}\ \rightarrow\ \mathrm{X}_{[+\text{son}]}\ \text{s} \]
    \item[P4] \textbf{爆发音鼻化}：爆发音在鼻音前同化为与原爆发音同部位的鼻音\footnote{鼻化保留原发音部位，可视为后接鼻音的[$+$nasal]自主音段向左扩展、而发音部位节点不变\parencite{clements1995internal}。}：
    \[ \begin{bmatrix}-\text{son}\\[-1pt]-\text{cont}\end{bmatrix}\rightarrow[+\text{nasal}]\ \;/\;\ \rule[2pt]{1em}{0.4pt}\,[+\text{nasal}] \]
    即/p, t, k/在鼻音前分别变为/m, n, ŋ/。
    \item[P5] \textbf{鼻音簇缩减}：相邻两鼻音中，居后的/n/或/ŋ/删除，腭鼻音/ɲ/不删除\footnote{/ɲ/豁免可能因为它是2\textsc{pl}/3\textsc{pl}的唯一语音体现。}：
    \[ \text{n, ŋ}\rightarrow\emptyset\ \;/\;\ [+\text{nasal}]\,\rule[2pt]{1em}{0.4pt} \]
    \item[P6] \textbf{咝音前缩减}：齿龈音/s, t, n/在/ʃ/前删除\footnote{依规则同时施用的约定\parencite{Chomsky1968-sp}，本规则对 /nsʃ/ 一类序列只删除紧邻 /ʃ/ 的 /s/，不会连带删除其左侧、当时尚不与 /ʃ/ 相邻的 /n/（详见下文 /-s/+/-nʃ/ 的推导）。}：
    \[ \text{s, t, n}\rightarrow\emptyset\ \;/\;\ \rule[2pt]{1em}{0.4pt}\,\text{ʃ} \]
    \item[P7] \textbf{去鼻化}：双唇鼻音/m/在/j/前变为同部位爆发音/p/：
    \[ \text{m}\rightarrow\text{p}\ \;/\;\ \rule[2pt]{1em}{0.4pt}\,\text{j} \]
    \item[P8] \textbf{/ɲ/滑音化}：腭鼻音/ɲ/在/s/前变为同部位滑音/j/：
    \[ \text{ɲ}\rightarrow\text{j}\ \;/\;\ \rule[2pt]{1em}{0.4pt}\,\text{s} \]
\end{enumerate}

八条规则按 P1 $\gg$ P2 $\gg$ P3 $\gg$ P4 $\gg$ P5 $\gg$ P6 $\gg$ P7 $\gg$ P8 的次序运用。按照\textcite{Kiparsky1968-fb}的分类，若规则$A$的输出为规则$B$创造新的可施用环境且$A$先于$B$，二者构成馈给（feeding）；若$A$摧毁$B$的环境且$A$先于$B$，则构成榨取（bleeding）。当本应馈给/榨取的规则反被排在后面时，相应地构成逆馈（counterfeeding）与逆榨（counterbleeding），并在表层留下不透明性（opacity）\parencite{Kiparsky1973-op,mccarthy2007hidden}。米亚罗话复辅音韵尾的推导中，上述四种交互类型均有体现：

\begin{itemize}
    \item P1榨取P4：P1删除2\textsc{sg}后缀/n/，从而移除了P4鼻化所需的鼻音触发环境。由于P1先于P4，闭音节动词的2\textsc{sg}形式不发生鼻化，如/-k/+/-n/ $\rightarrow$ [-k]。
    \item P3馈给P8：P8要求/ɲ/紧邻其后的/s/，而这一相邻关系需要由P3的咝音换位创造。P3先于P8，因此例如/-s/+/-ɲ/才能顺利推导为 [-js]。
    \item P5逆榨P4：在/-ps/+/-nʃ/中，P4须借助居中的/n/把/p/鼻化为/m/，其后P5又删去这个/n/，导致了表层的不透明性。如果颠倒次序先删/n/，则/p/失去鼻化条件，错误地得到$^*$[-pʃ]。
    \item 逆馈：P2使/p/在/j/前弱化为/w/，以及P7使/m/在/j/前变为/p/两条规则，在与其他规则互动时有一些逆馈的例子：
    \begin{itemize}
        \item P3逆馈P2：/-ps/+/-j/底层/-psj/中/p/与/j/要P3换位后才相邻，但P3排在P2之后，所以/p/保留，输出[-pjs]而非$^*$[-wjs]。
        \item P8逆馈P7：/-ps/+/-ɲ/中，P8把/ɲ/滑音化为/j/，使前面经P4鼻化而来的/m/处于/j/前。由于P8排在P7之后，因此不会经过P7变为[p]，而是输出[-mjs]。
    \end{itemize}
\end{itemize}
